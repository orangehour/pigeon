# Pigeon

Support page and privacy policy for Pigeon, the iPhone app that keeps count of what you eat, drink and do. GitHub Pages serves this folder as is (`.nojekyll`):

- Support: https://orangehour.github.io/pigeon/support/
- Privacy Policy: https://orangehour.github.io/pigeon/privacy/

The root redirects to Support. App Store Connect links to both, so keep these two paths. The privacy policy must match the App Privacy answers in App Store Connect (Data Not Collected); change both together, and update the policy's effective date.

Found a bug or have a question about the app? Email pigeonlogeverything@gmail.com.
